# Scoring Philosophy

Score must reflect reality. If a flight was terrible, the score says so — don't let bonuses or missing detections inflate a bad flight.

**Why:** First test scored 109/S on a flight where Brian crashed into a lake. Crash detection missed the water impact and a greaser bonus fired before the excursion.

**Rules:**
- Crash or runway excursion = automatic F, no exceptions
- Suppress landing quality bonuses on crash/excursion
- Approach checks must fire even when Cruise/Approach phase is never entered (pattern flights)
- Add events aggressively, tune thresholds after seeing data
- When in doubt, make bad events harder to score through, not easier
