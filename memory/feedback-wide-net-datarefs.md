# Wide Net on Datarefs

When expanding what the client captures, add all potentially useful datarefs upfront. Log raw values so we can review after a real flight and decide what's actionable vs noise.

**Why:** Brian explicitly said "cast a big net now." Better to have too much data and prune than to add incrementally and miss useful signals.

**How to apply:** Propose the full set, not a conservative subset. Log raw values in the `.log` file. Don't pre-filter — let the data decide what gets kept.
